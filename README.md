# ✈️ Trippings

**Trippings** is a web-based flight booking system that allows users to search for flights, book tickets, manage reservations, and view their travel history. This project was developed in **partial fulfillment of the requirements for CCDEVAP (Application Development)** at **De La Salle University**.

## 📖 Overview

Trippings provides a simple and intuitive platform for booking flights online. It streamlines the reservation process by allowing users to browse available flights, create bookings, and manage their travel information through a clean web interface.

Developed in partial fulfillment of the **CCDEVAP** course requirements, the project showcases full-stack web development concepts including user authentication, CRUD operations, relational database management, and responsive web design using  Node.js, MongoDB, HTML, CSS, JavaScript, and Bootstrap.


## ✨ Features

### User Features
- 🔐 User Registration & Login
- ✈️ Browse Available Flights
- 📅 Book Flight Tickets
- 🎫 View Booking History
- ❌ Cancel Reservations
- 👤 Manage User Profile

### Admin Features
- Manage Flights
- Add, Edit, and Delete Flight Information
- View User Bookings
- Manage Customer Accounts
